# MR SUIT — Premium Bespoke Menswear Website

A luxury multi-page enquiry and presentation website for **MR SUIT Bespoke Suits** (Vadapalani, Chennai).

## Quick Start
```bash
npm install
npm run dev
```
Visit: `http://localhost:5173/`

## Production Build
```bash
npm run build
npm run preview
```

## Structure
- `/` — Homepage featuring editorial 3-slide hero carousel, collection showcase, atelier craftsmanship, and store spotlight.
- `/stores/` — Dedicated Stores page with Vadapalani showroom imagery, address, and Google Maps integration.
- `/customization/` — 4-Step bespoke tailoring process (Fabric, Measurements, Tailoring, Final Fitting) and cloth library.
- `/about-us/` — Sartorial philosophy, brand ethos ("Completes Your Desire"), and tailoring standards.
- `/contact/` — Direct contact details, click-to-call, email, WhatsApp, and salon directions.
- `/enquiry/` — Interactive bespoke consultation form with prefilled WhatsApp enquiry dispatcher.
